# 四类症状自检表（评论区 / 技能包 README 用）

> 2026-11-02 · 鱼人判庭虚之理。这张表配套「装插件炸机」那条排查。**表放评论区与 README，不塞进片子**——主题只有一件事。

| 症状 | 根因 | 动作 | 归属 |
|---|---|---|---|
| 只剩 Electron 原子图标／`path-to-app` 默认页 | app.asar 头部索引与数据区错位 | 换干净底包 | **与插件无关** |
| 登录一直转圈／全模型 fetch failed | 代理环境变量残留 | 清掉环境变量 | **与插件无关** |
| 装完 DSH 起不来 | profile 被 pnpm 按残缺 lock 清理过 | 从备份拷回，**别再手跑 pnpm install** | **这就是装插件炸的**（＝本包 §3 末那条警告） |
| 插件列表里根本看不到它 | locale 缺 `meta` 包裹 | 补 meta + exports/files 接线，重启 | 登记那一步没做完 |
| 启停插件报 `root Include entry` | profile 里留了宿主包副本 | 移走副本，完全重启 | 救机副作用 |

> **五行里只有第三行是「装插件」本身造成的，其余四行是别的病——撞上了照表走，别改流程。**

> **配图**：这张表就是它的配图——表即图，按行对症状，比截图快。
